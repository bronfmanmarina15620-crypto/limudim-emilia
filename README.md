# הלימודים של אמיליה

אפליקציה אחת לתרגול של אמיליה (כיתה ה1, מגד), עם כל מקצועות התרגול בפנים.

כתובת: https://bronfmanmarina15620-crypto.github.io/limudim-emilia/

- עדכון «מה בשבוע הזה» ורשימת הכרטיסים: בקובץ `data.js`.
- אזור ההורים (קוד משפחתי, בלי להציג אותו במסך) נמצא באפליקציה המרכזית בלבד. הוא רק קורא את נתוני התרגול — לא מוחק ולא משנה מפתחות שמירה או שורות ענן.
- כל מקצוע יושב בתיקייה משלו (`kefel/`, `hiluk/`, `geometry/`, `arabic/`, `hisur/`, `hisur/mivhan/`, `hisur/seder/`). המפתחות והשורות בענן נשארים כמו שהיו.
- המאגרים הישנים נשארים, ודפי הכניסה שלהם מפנים לכאן (כולל `?section=geo`).

פירוט לבוטים שמתחזקים מקצוע: ראו `HANDOFF.md`.
